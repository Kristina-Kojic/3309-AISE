# TripSync ✈️

**Group Travel Planning & Expense Management System**
AISE 3309 – Database Management Systems | Group 3

TripSync is a database system that helps groups travelling together plan their trips (accommodations, transportation, activities) and manage shared expenses, so everyone knows who paid for what and who owes who.
